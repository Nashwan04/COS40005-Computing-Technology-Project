# Example proofs (small SYNTHETIC fixture data only)

- `yelp_tiny_shared_business.html`: HTML example from three small **SYNTHETIC** Yelp-format records, with raw source record checks.
- `yelp_tiny_proof.json`: selected actual source-to-graph evidence for the synthetic example.
- `dblp_small_shared_author.html`: generated graph from the bundled 4-paper **SYNTHETIC** DBLP-style teaching example.
- `synthetic_5000_runlog.txt` and `synthetic_5000_validation.txt`: output from executing the 5,000-paper **SYNTHETIC** scalability test.

These examples are included so the project can be shown offline. They are **not proof of running downloaded Yelp/DBLP datasets**.
